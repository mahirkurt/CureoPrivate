# brand-maker-ecosystem v1.0 — Ecosystem Companion Skill

**Skill type:** Reference companion for the existing brand-maker
**Version:** 1.1.0
**Ecosystem:** Brand Ecosystem v1.0

## 1. Raison d'être

This skill is a **reference companion** for the existing `brand-maker` skill. It provides four extension references that enable brand-maker to consume ecosystem upstream handoffs (brand-platform, brand-story) without modifying brand-maker's core 5-step methodology (Strategic Decoding → Five-Category Brainstorm → SMILE+M Lab → Live Domain → Post-Digital Validation).

This skill **does not produce names on its own**. It supplements brand-maker's naming work with ecosystem-aware strategic context. Names are still generated by brand-maker.

## 2. When This Skill Activates

This skill activates automatically when:

- `brand-maker` is being invoked AND
- One or more of the following conditions hold:
  - Upstream artifact from `brand-platform` is present (brand_platform_handoff)
  - Upstream artifact from `brand-story` is present (brand_story_handoff)
  - The brief contains luxury sector signals (luxury, premium, haute couture, fine jewelry, exclusive)
  - The brief contains explicit sector context that maps to Wiedemann/Taschen taxonomy
  - The brief explicitly requests archetype-driven naming

When activated, this skill provides reference material that brand-maker's 5-step methodology consults during the **Strategic Decoding** and **Five-Category Brainstorm** phases.

## 3. Reference Files

### `references/storybrand-sb7-brief.md`

Translates the BrandScript artifact (from brand-story) into a naming brief layer. Maps SB7 elements to naming biases:

- **Character (Customer)** → semantic territory of names
- **Problem (three-layer)** → oppositional stance the name takes
- **Guide (brand role)** → authority register of names (sage / mentor / partner / catalyst)
- **Plan** → pronunciation friction (heroic plans favor punchy names; complex plans favor warm names)
- **CTA** → gravity calibration (direct CTAs favor short names; transitional CTAs permit warmer poetic names)
- **Failure** → opposite signal (the kind of name the failure-state brand would have)
- **Success** → affect target (uplift, calm, awe, intimacy)

### `references/personality-frameworks-extended.md`

Extends brand-maker's standard personality reference with the composite framework brand-platform produces (Jung archetype + Aaker 5-D + voice traits). Provides archetype-driven naming bias tables:

- **Sage** favors substantive coinages, Latin/Greek roots, gravitas
- **Jester** permits sonic playfulness, wordplay, unexpected combinations
- **Ruler** leans toward heritage references, established forms, sovereign vocabulary
- **Magician** favors transformational verbs, mystery markers
- **Hero** rewards punchy mono- or bi-syllabic names with hard consonants
- **Outlaw** breaks convention, includes friction
- **Caregiver** warms toward soft consonants, gentle vowels
- **Lover** favors sensual rhythm, poetic forms
- **Explorer** rewards open vowels, motion verbs
- **Creator** privileges making/forming references
- **Innocent** favors simplicity, transparency
- **Everyman** stays accessible, common-tongue

### `references/global-sector-taxonomy.md`

Condensed reference from Wiedemann's Taschen *Logo Design: Global Brands* — the 9-sector classification (Industry & Trade, Information & Media, Sports & Travel, Health & Beauty, Architecture & Construction, Communications & Marketing, Retail & Lifestyle, Services & Finance, Culture & Education). Each sector has documented naming conventions, allowing brand-maker to either align with or deliberately depart from them.

### `references/luxury-naming-constraints.md`

Opt-in module mirroring brand-platform's luxury opt-in. When luxury context is present, applies Derval-derived luxury naming constraints:

- Founder-name precedent (the strongest luxury naming pattern)
- Heritage signaling (founding date, lineage, atelier reference)
- Classical forms (Latin, Greek, French, classical English)
- Restraint (no neologisms, no portmanteau, no compound coinage)
- Tier-fit calibration (super-luxury / luxury / affordable luxury / avant-garde luxury)

## 4. How Composition Works

When `brand-maker` is called and the trigger conditions are met:

1. brand-maker enters its standard Strategic Decoding phase
2. brand-maker-ecosystem provides additional reference: BrandScript translation, archetype bias, sector taxonomy, luxury constraints
3. brand-maker uses the enriched context during Five-Category Brainstorm — A/B/C/D/E categories are weighted differently per the enrichment
4. brand-maker's SMILE+M Lab evaluates candidates with additional rigor (does the candidate honor the archetype? does it respect luxury restraint?)
5. brand-maker's output handoff carries forward the enrichment as documented decisions
