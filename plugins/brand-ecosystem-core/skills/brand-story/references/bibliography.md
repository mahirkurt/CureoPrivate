## Skill-Specific Deep Cuts

### Heath, Chip and Dan Heath. *Made to Stick: Why Some Ideas Survive and Others Die*. Random House, 2007.

SUCCESs framework (Simple, Unexpected, Concrete, Credible, Emotional, Story) — validation criteria for BrandScript output. Miller's CTAs are reinforced by Heath's concrete + credible gates.

Used in: All output documents for stickiness validation.

Citation: `[Heath & Heath, SUCCESs]`

### Sinek, Simon. *Start With Why: How Great Leaders Inspire Everyone to Take Action*. Portfolio, 2009.

Golden Circle (Why → How → What) maps to Miller's three-layer problem (philosophical → internal → external). Sinek's framing especially illuminates Miller's philosophical layer.

Used in: `references/three-layer-problem.md`

Citation: `[Sinek, Golden Circle]`

### Aaker, David, and Joachim Aaker. *Brand Portfolio Strategy*. Free Press, 2004.

Sub-brand narrative architecture. When a parent brand has multiple sub-brands, BrandScript framework applies recursively. Aaker portfolio decisions inform when recursive scripting is required.

Used in: Conditional reference when multi-brand portfolio context detected.

Citation: `[Aaker, Portfolio]`

## Citation Discipline Rule

Every SB7 element in the BrandScript output must carry an inline citation. Empty narrative claims without source backing are downgraded.

When citing the three-layer problem framework, always cite `[Miller, Ch. 4]` as primary source. When using the philosophical layer's relationship to Sinek's Why, both citations apply: `[Miller, Ch. 4]; [Sinek, Golden Circle]`.
