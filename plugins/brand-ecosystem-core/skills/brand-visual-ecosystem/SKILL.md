# brand-visual-ecosystem v1.0 — Ecosystem Companion Skill

**Skill type:** Reference companion for the existing brand-visual
**Version:** 1.1.0
**Ecosystem:** Brand Ecosystem v1.0

## 1. Raison d'être

This skill is a **reference companion** for the existing `brand-visual` skill. It provides five extension references enabling brand-visual to operate as one node in the seven-skill ecosystem chain — consuming upstream brand-audit + brand-platform context and producing downstream-anticipating outputs for brand-touchpoint, brand-launch.

This skill **does not produce visual identities on its own**. Visual identities are still generated by brand-visual.

## 2. When This Skill Activates

This skill activates automatically when:

- `brand-visual` is being invoked AND
- One or more of the following conditions hold:
  - Downstream brand-touchpoint work is anticipated (or explicitly in scope)
  - Upstream brand-audit visual_white_space analysis is present in the handoff
  - Corporate B2B opt-in module is active from brand-platform
  - Multi-sensory dimensions are in scope (hospitality, retail, luxury, automotive, fine dining)
  - Brand center / Phase 5 governance preparation is anticipated

When activated, this skill provides reference material that brand-visual consults during its 4-route exploration phase, UMMP construction, and final specification output.

## 3. Reference Files

### `references/touchpoint-atmosphere-system.md`

When brand-visual knows brand-touchpoint is downstream, the output produces specifications with touchpoint anticipation:
- Material atlas (paper stocks, signage substrates, packaging materials, fabric weights for uniforms)
- Motion language (animation cadence, transition curves, kinetic identity behavior)
- Scale specimens (how the identity behaves at 16px favicon and at 30m billboard)
- Sensory layer specifications (acoustic profile, scent stance, tactile finish)
- Atmospheric descriptors (warmth/coolness, density/openness, gravity/lightness)

These specifications flow forward as brand-touchpoint constraint.

### `references/corporate-signature-academic.md`

Foroudi/Olins corporate brand signature methodology. When corporate B2B opt-in is active, treats the visual identity as a corporate identity system rather than consumer brand mark:
- Formal lockup hierarchy (primary signature, secondary signatures, lockup-with-tagline, lockup-with-descriptor)
- Brand architecture lockup rules for monolithic / endorsed / pluralistic systems
- 9-cell identity mix coverage (Foroudi et al., Chapter 7)

### `references/sensory-neuromarketing.md`

For brands requiring multi-sensory dimensions (hospitality, retail, luxury, automotive, fine dining):
- Sonic logo brief (mnemonic structure, timbre palette, motif development)
- Scent strategy stance (ambient vs. signature scent; substance vs. associative)
- Tactile material recommendations (paper finish vocabulary, textile choices)
- Music palette brief (era, instrumentation, tempo range, mood gradient)
- Voice character (announcer or AI voice persona for audio touchpoints)

Atmosphere as system, not just identity as visual.

### `references/competitive-audit-protocol.md`

When upstream brand-audit handoff is present, this reference enables brand-visual to consume the visual_white_space block intelligently:
- How to read competitive color positioning maps
- How to identify form-language white space in a category
- How to verify proposed identity routes don't collide with competitor signatures
- How to document deliberate visual departures with rationale

### `references/phase5-asset-management.md`

Wheeler Phase 5 asset management specifications:
- File naming conventions (kebab-case, version suffixes, lock files)
- Design tokens (color tokens, typography tokens, spacing tokens, motion tokens)
- Brand center asset preparation (which assets, in which formats, at which resolutions)
- Asset retirement policy (deprecation paths)

Prefigures brand-launch's brand center build specification downstream.

## 4. How Composition Works

When `brand-visual` is called and trigger conditions are met:

1. brand-visual reads upstream handoffs (brand-platform, brand-audit if rebrand, brand-story)
2. brand-visual-ecosystem provides additional reference layers during the 4-route exploration phase
3. brand-visual produces its visual identity system with downstream-anticipating specifications (material, motion, sensory)
4. brand-visual's output handoff carries forward ecosystem-aware decisions
5. brand-touchpoint downstream consumes the enriched handoff

## 5. Handoff Schema
