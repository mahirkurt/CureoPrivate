# Touchpoint Atmosphere System — Reference for brand-visual

Loaded when brand-visual produces outputs that will be consumed by brand-touchpoint downstream.

## Why brand-visual must anticipate touchpoints

A visual identity designed only for the website + logo + favicon underserves the downstream touchpoint design work. Brand-touchpoint will produce specifications for stationery, signage, packaging, environment, vehicle livery, uniforms — each requires material, motion, scale, and sensory considerations the standard visual identity rarely addresses.

When brand-visual knows brand-touchpoint will follow, it produces specifications with touchpoint anticipation baked in.

## What "touchpoint anticipation" adds to brand-visual outputs

### Material specifications

Beyond color hex codes and font names:
- **Paper stock recommendations** for stationery: weight, finish, color, texture
- **Substrate recommendations** for signage: metal, wood, painted, illuminated
- **Packaging material recommendations**: paperboard grade, plastic type, glass, sustainable options
- **Environmental material recommendations**: flooring, wall treatments, fixture materials

These can't be picked at the touchpoint design stage if the visual identity didn't consider them.

### Motion language

For brands using Route 1, 2, or 3 (traditional), motion language is typically minimal. For brands using Route 4 (Adaptive Living Identity), motion is core.

Motion specifications include:
- Logo animation principles
- Transition character (snappy / smooth / playful / restrained)
- Interactive feedback motion (hover, scroll, load)
- Video graphic motion language
- Sonic-motion sync (if sonic logo exists)

These specifications inform digital touchpoints AND environmental touchpoints (kinetic signage, ambient screen content, projection mapping).

### Scale considerations

Visual identity tested across scales:
- Favicon: 16px to 32px
- Mobile UI: 24px to 60px
- Web hero: 60px to 400px
- Print: 6mm to A0
- Signage: meters
- Building-scale: ten-meter range

A logo that works at favicon but breaks at signage scale (because it relies on detail invisible at distance) fails touchpoint application.

### Sensory layers

Beyond visual:
- Sonic logo brief (and where it appears)
- Scent strategy stance (deliberate/absent)
- Tactile recommendations
- Auditory atmosphere recommendations
- Multi-sensory coherence

These appear in some brands (hospitality, retail, luxury) and not others (B2B SaaS), but the visual identity must declare which layers will be developed.

### Adaptive identity rules (Route 4)

If brand-visual selects Route 4 (Adaptive Living Identity), the rules system must be explicit:

- Core element invariants (what never changes)
- Modulating elements (what varies by context)
- Variation rules (how variation is constrained)
- Anti-patterns (what would break the system)

Without explicit rules, downstream touchpoint design treats Route 4 as license for inconsistency.

## Touchpoint-anticipating output extensions

When brand-visual knows brand-touchpoint is downstream, the output adds:

### Material atlas
A reference document specifying:
- Recommended materials per touchpoint category
- Material rationale (why this material expresses this brand)
- Material alternatives (for budget or sourcing flexibility)
- Material anti-patterns (materials that would break atmosphere)

### Scale specimens
Logo + identity system demonstrated at touchpoint scales:
- Business card scale specimens
- Letterhead specimens
- Signage specimens (1:1 if possible, or scaled with viewing-distance note)
- Packaging specimens
- Web specimens
- Mobile specimens

### Motion specifications
Even for non-Route-4 brands:
- Logo build / reveal animation (one canonical version)
- UI interaction motion principles
- Video graphic motion language
- Loading state motion

### Sonic brief
For brands where audio identity is in scope:
- Sonic logo concept brief (handoff to audio designer)
- Music character notes
- Voice character notes (for video / podcast brand voice)

### Atmospheric descriptors
3-5 descriptors that the visual identity intends to produce:
- These flow forward to brand-touchpoint as constraint
- brand-touchpoint reads atmospheric descriptors and produces touchpoints reinforcing them

## Anti-patterns

| Anti-pattern | Symptom |
|---|---|
| Digital-only visual identity | Logo + favicon + web mockups; no material, motion, scale specs |
| Logo-without-system | Mark designed, but no system for application across touchpoints |
| Material absence | Visual identity specifies digital but stays silent on physical materials |
| Scale failure | Logo works at one scale; fails at others; touchpoint design can't recover |
| Motion absence | Visual identity static-only when downstream digital touchpoints need motion |
| Sensory dimension blindness | Sector demands multi-sensory; visual identity treats only visual |
