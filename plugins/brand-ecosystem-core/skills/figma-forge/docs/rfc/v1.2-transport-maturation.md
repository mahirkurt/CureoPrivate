# RFC v1.2: Transport Layer Maturation

> Status: **Accepted & Shipped** (v1.2.0 GA) · 2026-05-28
> Target sürüm: **v1.2.0** — shipped across alpha.1 → alpha.2 → beta.1 → GA
> Author: figma-forge maintainers
> Supersedes the v1.2 roadmap items in RFC v1.1 §10.3

## 1. Motivation

RFC v1.1 shipped the transport layer abstraction with three concrete
adapters (Stub, PluginCapture, REST) and a placeholder for the MCP
adapter. RFC v1.1 §10.3 named three follow-on items for v1.2:

1. Live MCP transport
2. Backoff policy & rate-limit awareness
3. Real-time concurrency detection

This RFC records the design and acceptance of all three, plus a
fourth feature that emerged as a natural companion — **nested-instance
composition** for patterns — and a validation milestone for
**mixed-router** hybrid dispatch.

## 2. Features shipped

### 2.1 McpCursorTransport (alpha.1)

The fourth concrete adapter. Mirrors PluginCapture's "emit an artifact
an external executor runs" model: where PluginCapture emits a
TypeScript script, McpCursor emits an **MCP tool-call plan** (JSON)
that an MCP-capable agent executes against a live Figma file.

Two dispatch mechanisms, recorded per descriptor and declared in the
capability matrix:

- `native` (5 ops) — a dedicated Figma MCP tool exists; deterministic
  (`create_new_file`, `get_metadata`, `get_variable_defs`,
  `send_code_connect_mappings`, `get_code_connect_map`).
- `supported-nl` (the rest) — expressed as a natural-language
  instruction for `Figma:use_figma`; best-effort, non-deterministic.

A new capability level `supported-nl` was added to make the
native-vs-natural-language distinction explicit rather than papering
over it. McpCursor is **opt-in** (excluded from the default router) to
avoid silent plan emission in non-agent environments.

### 2.2 Nested-instance composition (alpha.2)

Two new transport operations (`place_instance`,
`set_instance_property`) and a new reference type (`InstanceRef`),
taking TRANSPORT_OPERATIONS from 19 to 21 (append-only). Patterns now
place real nested instances of their `composition.uses_components`
inside the pattern frame, rather than only recording composition
metadata in the description.

Per-adapter: Stub no-op; PluginCapture emits real
`createInstance()` + `appendChild` + `setProperties` TypeScript; REST
declares `unsupported` (the REST API has no instance-write endpoint)
and raises `CapabilityUnsupportedError`; McpCursor emits `use_figma_nl`.

### 2.3 BackoffPolicy (alpha.2)

A pure-arithmetic retry policy (`max_retries`, `base_delay`,
`max_delay`, `jitter`, `jitter_ratio`, `honor_retry_after`, `seed`)
wired into `RestTransport`. Transient failures (429, 5xx, network) are
retried; a server-supplied `Retry-After` is honored; non-transient 4xx
errors are never retried. The policy does not sleep — the caller does
— which keeps it unit-testable without real time passing.

### 2.4 Concurrency detection (beta.1)

`run_pipeline(detect_concurrency=True)` snapshots the target file's
`last_modified` before the build and re-checks after, attaching a
`ConcurrencyReport` and a warning when another editor modified the
file during the run. `check_concurrency` and `ConcurrencyReport` are
public; `FileRef` gained an append-only `last_modified` field. The
check is best-effort: adapters that can't read live state report
`checked=False` and never fail the build.

### 2.5 Mixed-router validation (beta.1)

End-to-end test coverage of a four-adapter router proving that, with a
credentialed REST adapter, Variables and Code Connect route to REST
while component/pattern/instance operations fall through to
PluginCapture — the real-world hybrid dispatch the router was designed
for.

## 3. Public API delta

The surface grew from 32 (v1.1.0) to 36 symbols (v1.2.0), all
additive; `API_VERSION` stays `"1.0"`:

| Symbol                 | Kind      | Milestone |
|------------------------|-----------|-----------|
| `McpCursorTransport`   | class     | alpha.1   |
| `BackoffPolicy`        | dataclass | alpha.2   |
| `ConcurrencyReport`    | dataclass | beta.1    |
| `check_concurrency`    | function  | beta.1    |

Plus `InstanceRef` in `transport.__all__` (transport-level, like other
reference types). Operation count 19 → 21. New capability level
`supported-nl`.

## 4. Acceptance Criteria for v1.2.0 GA

- [x] `McpCursorTransport` implements all supported operations, emits a
      well-formed MCP tool-call plan, distinguishes native vs
      use_figma_nl, and is opt-in (alpha.1)
- [x] Capability matrix promotes all 18 MCP-Cursor cells from
      `deferred-v1_2` to real levels; `supports()` matches the matrix
      for every operation (alpha.1)
- [x] `place_instance` / `set_instance_property` implemented across all
      four adapters with correct capability declarations; REST raises
      `CapabilityUnsupportedError` (alpha.2)
- [x] `_run_patterns` places real nested instances; validated at 76
      instances on the Düstur fixture (alpha.2)
- [x] `BackoffPolicy` honors `Retry-After`, falls back to exponential
      with jitter, retries transient-only, and is unit-testable
      without real sleep (alpha.2)
- [x] `BackoffPolicy` wired into `RestTransport`; 429 retry verified via
      the mock Figma server (3 attempts + 2 honored sleeps) (alpha.2)
- [x] Concurrency detection: `check_concurrency` + `ConcurrencyReport`,
      `run_pipeline(detect_concurrency=True)`, best-effort graceful
      degradation; verified unchanged/modified/unsupported paths
      (beta.1)
- [x] Mixed-router hybrid dispatch validated end-to-end across REST +
      PluginCapture + McpCursor + Stub (beta.1)
- [x] Public API additive only; `API_VERSION` unchanged at `"1.0"`;
      all 36 symbols resolve; `api/STABILITY.md` updated (GA)
- [x] No regression: 220 pytest + 8 verification gates = 228/228 (GA)
- [ ] **Live integration test against a real Figma file / live MCP
      host** — DEFERRED, as in v1.1. The sandbox has no egress to
      `api.figma.com`, no Enterprise PAT, and no live MCP Figma host.
      All dispatch and plan-emission paths are mock-verified; the
      operator executes against the real API / a real agent. A
      `pytest -m live` convention is documented in the walkthroughs.

**Status: 9 of 10 criteria MET. The 10th (live real-Figma / real-MCP
integration) is structurally impossible in the sandbox and is
delegated to the operator's environment — the infrastructure is
complete and mock-verified. v1.2.0 GA ships on this basis,
consistent with the v1.1.0 GA precedent.**

## 5. Deferred beyond v1.2.0

- Promotion of `use_figma_nl` MCP operations to `native` as Figma's
  MCP write surface matures (non-breaking when it happens)
- A reference agent-side plan executor (consumes `render_mcp_plan()`
  output and drives the Figma MCP tools) — currently the operator /
  agent implements this
- Parallel / batched dispatch for independent operations
