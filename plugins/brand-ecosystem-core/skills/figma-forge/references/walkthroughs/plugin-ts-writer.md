# Plugin Channel TypeScript Writer (G14 + G13)

> Status: v0.3.0-beta.1 (initial); v0.3.1 (G14 + G13 production-grade)

The plugin channel renders remediation actions as **paste-into-Figma**
TypeScript. The operator opens the target Figma file → Plugins →
Development → Open Console → pastes the script.

## G14 — Icon SVG → Figma Component (v0.3.1)

Production-grade flow:

1. **Tier-aware page routing** — Auto-creates the target page if
   absent: `Tier Icons`, `Selçuklu Motifleri`, `Document Icons`,
   `UI Icons`
2. **Canonical container sizing** — 24×24 for Tier/Document/UI,
   192×192 for Selçuklu motifs
3. **Idempotent re-runs** — Locates existing components by name via
   `findOne(ComponentNode)` and updates geometry in-place rather than
   duplicating
4. **Provenance trail** — Sets `component.description` with source
   path and generator attribution
5. **Documentation links** — Wires `component.documentationLinks` to
   the canonical source-of-truth path
6. **Template literal safety** — Escapes `\`, backticks, and `${`
   sequences in the embedded SVG

Generated script structure:

```typescript
(async () => {
  // ───── Action 1 · G14 · icons/svg/tier/anayasa-24.svg
  try {
    const svgString = `<svg ...>...</svg>`;

    // 1. Locate or create the target page
    let targetPage = figma.root.children.find(
      (p): p is PageNode => p.type === 'PAGE' && p.name === 'Tier Icons'
    );
    if (!targetPage) {
      targetPage = figma.createPage();
      targetPage.name = 'Tier Icons';
    }
    await figma.setCurrentPageAsync(targetPage);

    // 2. Import the SVG and resize to canonical container
    const importedNode = figma.createNodeFromSvg(svgString);
    importedNode.resize(24, 24);

    // 3. Locate existing component by name (idempotent re-runs)
    const existing = targetPage.findOne(
      (n): n is ComponentNode =>
        n.type === 'COMPONENT' && n.name === 'anayasa-24'
    );

    let component: ComponentNode;
    if (existing) {
      // Update geometry in place
      for (const child of [...existing.children]) child.remove();
      for (const child of [...importedNode.children]) existing.appendChild(child);
      existing.resize(24, 24);
      importedNode.remove();
      component = existing;
    } else {
      component = figma.createComponentFromNode(importedNode);
      component.name = 'anayasa-24';
    }

    // 4. Set description with provenance trail
    component.description = `Source: icons/svg/tier/anayasa-24.svg
Generated by figma-forge auto-remediate G14.`;

    // 5. Add documentation link
    component.documentationLinks = [
      { uri: 'https://github.com/<org>/<repo>/blob/main/icons/svg/tier/anayasa-24.svg' }
    ];
  } catch (err) {
    console.error('   ✗ Action 1 (G14) failed:', err);
  }
})();
```

## G13 — Variable Rebind Walker (v0.3.1)

When the merged DTCG has stale aliases that need rebinding in the live
Figma document:

1. **Rebind map extraction** — Parses the action rationale for
   `OLD → NEW` pairs (the G13 strategy embeds them as bullet lines)
2. **Cross-collection variable index** — Builds a `name → Variable`
   map across every local collection (primitives + semantics +
   theme-specific collections)
3. **Mode-iterative rebind** — For each pair, locates source and
   target variables, creates a `VariableAlias`, then calls
   `setValueForMode` for every mode the source variable defines
4. **Resilient logging** — Source-missing and target-missing cases
   warn but do not abort

Generated rebind block:

```typescript
const rebindMap = new Map<string, string>([
  ['color.semantic.anayasa.primary', 'color.tbk.9'],
  ['color.semantic.aym.primary', 'color.lacivert.8'],
]);

const allCollections = figma.variables.getLocalVariableCollections();
const varsByName = new Map<string, Variable>();
for (const coll of allCollections) {
  for (const varId of coll.variableIds) {
    const v = figma.variables.getVariableById(varId);
    if (v) varsByName.set(v.name, v);
  }
}

for (const [oldPath, newPath] of rebindMap.entries()) {
  const sourceVar = varsByName.get(oldPath);
  const targetVar = varsByName.get(newPath);
  if (!sourceVar || !targetVar) continue;

  const sourceColl = figma.variables.getVariableCollectionById(
    sourceVar.variableCollectionId
  );
  const alias = figma.variables.createVariableAlias(targetVar);
  for (const mode of sourceColl.modes) {
    sourceVar.setValueForMode(mode.modeId, alias);
  }
}
```

## Locale support

The header is locale-aware:

```bash
python3 scripts/auto_remediate.py \
    --output-channel plugin \
    --locale tr-TR \
    ...
```

Renders Turkish usage instructions:

```
// figma-forge auto-remediate — plugin TS scripti
// Figma → Plugins → Development → Open Console → bu scripti yapıştırıp Enter'a basın.
```

Otherwise (default `en-US`):

```
// figma-forge auto-remediate — plugin TS script
// Figma → Plugins → Development → Open Console → paste this script + press Enter.
```

## Run

```bash
python3 scripts/auto_remediate.py \
    --audit-report audit.json \
    --library-dir . \
    --output-channel plugin \
    --output-dir ./plugin-scripts/

# Output: ./plugin-scripts/figma-forge-remediations.ts
#         ./plugin-scripts/_summary.json
```

The plugin channel always writes a **single consolidated TS file** —
all actions concatenated into one IIFE. PR channel writes one `.patch`
per action.
