figma-forge importer

Channel 3 fallback. Writes tokens to Figma Variables + Styles.

⏳ Importing — please wait. Large libraries take 10–60 seconds.

What will be imported

SourceDTCG token JSON (embedded)
CollectionsPrimitives + Semantic + Dimension + Font
ModesLight + Dark (where present)
StylesPaint + Text + Effect

Notes

This plugin reads bundled tokens and writes Variables, paint styles, text styles, and effect styles to the current Figma file. The library will not be auto-published — you must run Assets → Publish Library manually afterward.
