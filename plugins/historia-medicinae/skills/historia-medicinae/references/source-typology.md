# Kaynak Tipolojisi — tür başına okuma kuralı

SOURCE_HUNT ve EDITIO modlarında yüklenir.

| Tür | Ne söyler | Okuma kuralı |
|---|---|---|
| **Tıbbî risale / ders metni** (Hippokratik külliyat, *Kânûn*, herbal, veba risalesi) | Dönemin **normatif** bilgisi | Pratiği değil, öğretilmesi gerekeni yansıtır. Külliyat ≠ tek yazar (Hippokratik korpus çok yazarlıdır) |
| **Vaka defteri / consilia** | Bireysel pratik | Seçilmiş ve çoğu kez başarı odaklı; temsil gücü sınırlı |
| **Hastane/tımarhane kaydı** | Kurumsal işleyiş | Kabul kriteri + form dayatması yeniden kurulmadan sayılmaz (`quellenkritik.md` §3) |
| **Ölüm cetveli / ölüm nedeni serisi** | Sertifikayı yazanın bilgisi | Patoloji değil pratik belgesi; ICD10h olmadan nicelleştirilmez |
| **Nizamnâme / yasa / yönetmelik** | Devletin **niyeti** | Uygulamayı kanıtlamaz; uygulama ayrı kaynakla gösterilir |
| **Meclis zabtı** (Hansard, TBMM) | Tartışmanın kendisi | Birincil; konuşmacı konumu ve tarih künyesiyle |
| **Resmî gazete / ilan** | Yürürlük ve tarih | Yayın kaydı kesindir; içerik yorumu ayrı |
| **Tıp dergisi (dönem)** | Mesleğin iç tartışması | Editoryal çizgi ve meslek çıkarı filtresi |
| **Meslek örgütü kaydı** | Meslekleşme süreci | Kutlayıcı anlatı riski |
| **Anatomi atlası / tıbbî illüstrasyon** | Görme biçimi | Görsel bir **argümandır**; nesnel kayıt değil. Pernkopf gibi lekeli kökenler için `ethics-of-atrocity.md` |
| **Cerrahi alet / maddi kültür** | Pratiğin izi | Müze künyesi + kullanım bağlamı |
| **Hasta mektubu / günlük / şikâyet** | "Hastanın sesi" | Kurumsal dolayım vardır (heteroglossia formülasyonu) |
| **Misyoner / sömürge raporu** | Yönetici bakışı | Yerli aktör **nesne** olarak görünür; postkolonyal okuma zorunlu |
| **Seyahatname** | Dışarıdan gözlem | Egzotikleştirme filtresi |
| **Biyografi sözlüğü / tezkire** | Prosopografi omurgası | Övgü türüdür; ölüm/görev tarihleri çapraz doğrulanır |
| **Paleopatolojik/aDNA bulgusu** | Maddî kanıt | Yalnız örneklenen bireyler için; genelleme yapılmaz |

**Ortak kural:** her kaynak türü için "kim, hangi zorunlulukla, hangi formda, kimi dışarıda
bırakarak" soruları sorulur (`quellenkritik.md` §1).
