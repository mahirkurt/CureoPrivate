# Md. 10-22 — Madde Yapısı ve Tipografi

## 1. Madde Numarası ve Başlığı

### 1.1. Format
```
MADDE 5- Bu Yönetmelikte geçen;
```

**Kurallar:**
- `MADDE` **kalın + büyük harf**
- Numaradan sonra **boşluk** yok, kısa çizgi (`-`) bitişik
- Sonunda **nokta yok**
- Altı çizilmez

### 1.2. Madde Başlığı (Md. 14)
**Format:**
```
**Tanımlar**
MADDE 5- Bu Yönetmelikte geçen;
    a) Bakanlık: Sağlık Bakanlığını,
    b) Kurum: Türkiye İlaç ve Tıbbi Cihaz Kurumunu,
```

**Kurallar:**
- **Kalın**
- **Yalnızca ilk kelimenin baş harfi büyük** (özel isim hariç)
- **Sonunda noktalama YOK**
- İçeriğe uygun
- **Çerçeve maddelere başlık konulmaz**

### 1.3. Yanlış örnekler
- ❌ `**TANIMLAR**` (büyük harf yasak — sadece kısım/bölüm başlıkları büyük)
- ❌ `**Tanımlar:**` (noktalama yasak)
- ❌ `**Tanımlar Maddesi**` (gereksiz uzatma)
- ❌ Çerçeve madde başında "Değiştirilen Hükümler" yazmak — başlık yok

## 2. Fıkra, Bent, Alt Bent Hiyerarşisi (Md. 13)

### 2.1. Fıkra — Numara ayraç içinde
```
MADDE 5- (1) Birinci fıkra metni.

(2) İkinci fıkra metni.

(3) Üçüncü fıkra metni.
```

### 2.2. Bent — Harf yarım ayraç
```
(1) Bu Yönetmelikte geçen;
    a) Bakanlık: Sağlık Bakanlığını,
    b) Kurum: Türkiye İlaç ve Tıbbi Cihaz Kurumunu,
    c) Ürün: Beşeri tıbbi ürünleri,
    ç) Ruhsat: Beşeri tıbbi ürün ruhsatını,
```

**Türkçe alfabe sırası:** `a, b, c, ç, d, e, f, g, ğ, h, ı, i, j, k, l, m, n, o, ö, p, r, s, ş, t, u, ü, v, y, z`

### 2.3. Alt bent — Numara yarım ayraç
```
a) Ruhsat türü:
   1) Tam ruhsat,
   2) Şartlı ruhsat,
   3) Acil kullanım ruhsatı,
```

### 2.4. z'den sonra
```
... 
z) Z bendi,
aa) AA bendi,
bb) BB bendi,
cc) CC bendi,
çç) ÇÇ bendi,
...
zz) ZZ bendi,
aaa) AAA bendi,
...
```

## 3. Tanımlar Maddesi Özel Kuralları

### 3.1. Alfabetik sıra zorunlu
Tanımlar **alfabetik sırada** dizilir. Türkçe alfabeye göre.

### 3.2. Sonradan eklenecek tanım
Mevcut bir tanımlar maddesine ek tanım yapılıyorsa **son bent** olarak eklenir; alfabetik sıra **bozulmaz** (mevcut bentler yerinde kalır).

### 3.3. Tanım yazım formatı
```
a) Bakanlık: Sağlık Bakanlığını,
b) Beşeri tıbbi ürün: 1262 sayılı İspençiyari ve Tıbbi 
   Müstahzarlar Kanunu kapsamındaki ilaçları,
c) Klinik araştırma: 13/4/2013 tarihli ve 28617 sayılı 
   Resmî Gazete'de yayımlanan Klinik Araştırmalar Hakkında 
   Yönetmelikte tanımlanan klinik araştırmaları,
```

**Kurallar:**
- Bent harfi sonrası: `:`
- Tanımlanan terim **kalın değil**, doğal Türkçe büyük harf kurallarına uygun
- Tanım sonrası **virgül**
- Son tanım sonrası **nokta**

## 5. Kısım ve Bölümler (Md. 12)

### 5.1. Hiyerarşi
```
KİTAP (en geniş — sadece çok kapsamlı taslaklarda)
└── KISIM
    └── BÖLÜM
        └── MADDE
```

### 5.2. Yazım Kuralları

| Düzey | Yazım | Örnek |
|-------|-------|-------|
| KİTAP | Kalın + büyük | `BİRİNCİ KİTAP` |
| KISIM | Kalın + büyük | `İKİNCİ KISIM` |
| BÖLÜM | Kalın + büyük | `ÜÇÜNCÜ BÖLÜM` |
| KİTAP/KISIM/BÖLÜM başlığı | Kalın + baş harfler büyük | `Genel Hükümler` |

**Altı çizilmez.**

### 5.3. Örnek
```
İKİNCİ KISIM
Ruhsat Başvurusu ve Değerlendirme

BİRİNCİ BÖLÜM
Başvuru Belgeleri

MADDE 5- ...
```

## 6. Ek ve Geçici Maddeler (Md. 16)

### 6.1. Ek madde — Yeni numara
```
EK MADDE 1- Bu Yönetmeliğin yürürlüğe girmesinden önce 
ruhsat başvurusu yapmış olanlara ilişkin hükümler...
```

### 6.2. Belirli bölüme ek — Slash/A formatı
```
MADDE 5/A- Şartlı ruhsat başvurusu...
```

Bu format **mevcut madde 5'in altına yeni bir madde** eklemek için kullanılır.

### 6.3. Mükerrer madde yasağı
Mevzuatta zaten "MADDE 5" varsa, ikinci kez "MADDE 5" YASAK. Yerine:
- `EK MADDE 1, EK MADDE 2, ...` (genel ek)
- `MADDE 5/A` (belirli bölüm içinde ek)

### 6.4. Geçici madde
Geçiş hükümleri **geçici madde** ile düzenlenir:
```
GEÇİCİ MADDE 1- Bu Yönetmeliğin yürürlüğe girdiği tarihten 
önce başlatılmış olan ruhsat başvuruları, başvurunun yapıldığı 
tarihteki mevzuat hükümlerine göre sonuçlandırılır.
```

**Kurallar:**
- `GEÇİCİ MADDE` kalın + büyük
- Numaralandırma: GEÇİCİ MADDE 1, GEÇİCİ MADDE 2, ...
- Başlık yok (çerçeve madde mantığı)

## 7. Çerçeve Madde Yapısı (Değişiklik Maddesi)

### 7.1. Tek değişiklik
```
MADDE 1- 11/12/2021 tarihli ve 31685 sayılı Resmî Gazete'de 
yayımlanan Beşeri Tıbbi Ürünler Ruhsatlandırma Yönetmeliğinin 
5 inci maddesinin birinci fıkrası aşağıdaki şekilde değiştirilmiştir.

"(1) Ruhsat başvurusu, başvuru sahibi ya da yasal temsilcisi 
tarafından Kuruma elektronik ortamda yapılır."
```

**Kurallar:**
- Çerçeve madde **başlıksız**
- Tarih + sayı + ad ilk atıfta tam
- "aşağıdaki şekilde değiştirilmiştir" formülü
- Yeni metin **tırnak içinde**
- **Satırbaşı yok** cümle değişiklik/eklemelerinde

### 7.2. Birden fazla değişiklik
```
MADDE 1- 11/12/2021 tarihli ve 31685 sayılı Resmî Gazete'de 
yayımlanan Beşeri Tıbbi Ürünler Ruhsatlandırma Yönetmeliğinin 
5 inci maddesi aşağıdaki şekilde değiştirilmiştir.

"MADDE 5- ..."

MADDE 2- Aynı Yönetmeliğin 7 nci maddesinin (a) bendi 
aşağıdaki şekilde değiştirilmiş ve aynı maddeye aşağıdaki 
fıkra eklenmiştir.

"a) Yeni (a) bendi metni,"

"(5) Yeni eklenen beşinci fıkra metni."
```

### 7.3. Mahkeme kararı ile iptal edilmiş hükmün yeniden düzenlenmesi
```
MADDE 3- Anayasa Mahkemesinin .../...K. sayılı kararıyla 
iptal edilen, 5510 sayılı Sosyal Sigortalar ve Genel Sağlık 
Sigortası Kanununun 73 üncü maddesinin üçüncü fıkrası 
aşağıdaki şekilde yeniden düzenlenmiştir.
```

**KRİTİK:** İptal edilmiş hükmün yeniden düzenlenmesi **çerçeve maddede açıkça belirtilir**.

## 8. Yürürlük ve Yürütme Maddeleri

### 8.1. Yürürlük
```
MADDE 25- (1) Bu Yönetmelik yayımı tarihinde yürürlüğe girer.
```

veya geçiş süresi varsa:
```
MADDE 25- (1) Bu Yönetmeliğin;
a) 5 inci maddesi 1/1/2027 tarihinde,
b) Diğer hükümleri yayımı tarihinde,
yürürlüğe girer.
```

### 8.2. Yürütme
```
MADDE 26- (1) Bu Yönetmelik hükümlerini Sağlık Bakanı yürütür.
```

veya çoklu:
```
MADDE 26- (1) Bu Yönetmelik hükümlerini Sağlık Bakanı ile 
Hazine ve Maliye Bakanı müştereken yürütür.
```

## 9. Adlandırma (Md. 11)

### 9.1. Müstakil mevzuat
```
**BEŞERİ TIBBİ ÜRÜNLER RUHSATLANDIRMA YÖNETMELİĞİ**
```

### 9.2. Değiştiren mevzuat
```
**BEŞERİ TIBBİ ÜRÜNLER RUHSATLANDIRMA YÖNETMELİĞİNDE 
DEĞİŞİKLİK YAPILMASINA DAİR YÖNETMELİK**
```

### 9.3. Yürürlükten kaldırıcı
```
**BEŞERİ TIBBİ ÜRÜNLER RUHSATLANDIRMA YÖNETMELİĞİNİN 
YÜRÜRLÜKTEN KALDIRILMASINA DAİR YÖNETMELİK**
```

**Kurallar:**
- **Kalın + büyük harf**
- **Altı çizilmez**
- Türkçe karakter doğru kullanılır

### 9.4. RG'de yayımlanan yönetmelik dışı türler
- **Karar** (Cumhurbaşkanı kararı)
- **Tebliğ**
- **Genelge**

Bunlar dışında "**Esaslar**", "**Usul**", "**Yönerge**", "**Talimat**" gibi adlar **yasaktır** (Md. 11/3).

## 10. Anti-Pattern Check (Pre-Submission)

- [ ] Madde başlıkları kalın + ilk kelime baş harfi büyük mü?
- [ ] Madde başlığında noktalama yok mu?
- [ ] Çerçeve maddelere başlık konmadı mı?
- [ ] MADDE numarası kalın + büyük + kısa çizgi bitişik mi?
- [ ] Tanımlar alfabetik sırada mı?
- [ ] Fıkra `(1)`, bent `a)`, alt bent `1)` formatında mı?
- [ ] z'den sonra `aa, bb, cc, çç, ...` doğru mu?
- [ ] Madde sıralaması Md. 15'e uygun mu?
- [ ] Kısım/bölüm başlıkları kalın + ilk harfler büyük mü?
- [ ] Ek madde için MADDE x/A formatı doğru kullanıldı mı?
- [ ] Geçici madde için "GEÇİCİ MADDE x-" formatı doğru mu?
- [ ] Çerçeve madde içinde değiştirilen metin tırnak içinde mi?
- [ ] Tırnak içinde satırbaşı yok mu (cümle değişiklik için)?
- [ ] Yürürlük tarihi tereddütsüz mü?
- [ ] Ekonomik/ticari etki varsa makul geçiş süresi var mı?
