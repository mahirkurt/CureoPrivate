# CONSORT 2010 — randomised controlled trials

Check each item; report present / missing / partial with locating text. Full
statement: Schulz KF et al. BMJ 2010;340:c332.

- **Title/Abstract (1)** — identified as randomised; structured abstract.
- **Introduction (2)** — background and rationale; specific objectives/hypotheses.
- **Methods (3–12)** — trial design + allocation ratio; eligibility + settings;
  interventions with detail to allow replication; pre-specified primary/secondary
  outcomes; sample-size determination; randomisation (sequence generation,
  allocation concealment mechanism, implementation); blinding (who was blinded);
  statistical methods.
- **Results (13–19)** — participant flow diagram (randomised → received → analysed →
  lost); recruitment dates; baseline table; numbers analysed per group;
  primary/secondary outcome results with effect size + precision (e.g. 95% CI);
  ancillary analyses; harms.
- **Discussion (20–22)** — limitations; generalisability; interpretation.
- **Other (23–25)** — registration; protocol availability; funding.

Red flags for LLM text: "double-blind" with no statement of who was blinded;
CONSORT flow numbers that do not add up; a p-value with no effect size / CI;
post-hoc outcomes presented as primary.
