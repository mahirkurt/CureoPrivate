# PRISMA-ScR — scoping reviews

Check each item; report present / missing / partial with locating text. Full
statement: Tricco AC et al. Ann Intern Med 2018;169:467. Use for SCOPING reviews
(mapping the literature); use PRISMA 2020 for systematic reviews with synthesis.

- **Title** — identifies the report as a scoping review.
- **Abstract** — structured summary (objectives, eligibility, sources, charting
  methods, results, conclusions).
- **Introduction** — rationale; objectives + the review question(s) with key
  concepts/population.
- **Methods** — protocol/registration; eligibility criteria (with rationale,
  incl. years/language); information sources + last search date; full search for
  ≥1 database; selection process; data-charting process + the items charted;
  critical appraisal of sources (optional in scoping — state if not done);
  synthesis/summary methods.
- **Results** — selection flow diagram; characteristics of sources; critical
  appraisal (if done); results of individual sources relevant to the question;
  synthesis of results mapped to objectives.
- **Discussion** — summary of evidence; limitations; conclusions + implications.
- **Other** — funding.

Red flags for LLM text: a scoping review framed as if it graded evidence
quality; a flow diagram whose numbers do not reconcile; "comprehensive" search
with no databases/dates.
