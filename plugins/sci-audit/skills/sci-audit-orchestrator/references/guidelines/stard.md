# STARD 2015 — diagnostic accuracy studies

Check each item; report present / missing / partial with locating text. Full
statement: Bossuyt PM et al. BMJ 2015;351:h5527.

- **Title/Abstract/Keywords** — identifies the study as a diagnostic accuracy
  study (sensitivity/specificity in the title); structured abstract.
- **Introduction** — scientific/clinical background; study objectives and
  hypotheses (target condition, index test, reference standard).
- **Methods** — study design (prospective/retrospective); eligibility criteria;
  where/how participants were identified and sampled (consecutive, random,
  convenience); index test + reference standard with rationale; technical
  specifications, definition of positivity/cut-offs, and whether these were
  pre-specified; whether readers of the index test were blinded to the reference
  standard and vice versa; how sample size was determined; analysis methods for
  estimating accuracy + handling indeterminate results and missing data.
- **Results** — participant flow diagram (eligible → tested → analysed);
  baseline characteristics; time interval between index and reference test;
  cross-tabulation of index vs reference results; estimates of accuracy with
  95% CIs; adverse events.
- **Discussion** — limitations incl. sources of bias and applicability;
  clinical implications.
- **Other** — registration; protocol; funding.

Red flags for LLM text: sensitivity/specificity with no 2×2 table or no CIs;
no reference-standard definition; unblinded readers not disclosed; a cut-off
that looks chosen after seeing the data.
