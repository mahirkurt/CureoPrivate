# STROBE — observational studies (cohort, case-control, cross-sectional)

Check each item; report present / missing / partial with locating text. Full
statement: von Elm E et al. Ann Intern Med 2007;147:573.

- **Title/Abstract (1)** — study design in title/abstract; informative summary.
- **Introduction (2–3)** — background/rationale; objectives with hypotheses.
- **Methods (4–12)** — design; setting/locations/dates; participants + eligibility
  and (for case-control) matching; variables (outcomes, exposures, confounders,
  effect modifiers) with definitions; data sources/measurement per variable; bias
  mitigation; study size rationale; handling of quantitative variables; statistical
  methods incl. confounding control, subgroups, missing data, sensitivity analyses.
- **Results (13–17)** — participants at each stage (flow); descriptive data +
  missingness; outcome events/summary; main results with confounder-adjusted
  estimates + CI, and the confounders adjusted for; other analyses.
- **Discussion (18–21)** — key results; limitations incl. bias direction;
  interpretation; generalisability.
- **Other (22)** — funding.

Red flags for LLM text: causal language ("X causes Y") on an observational
design; adjusted estimates with no list of covariates; "representative sample"
with no sampling frame.
